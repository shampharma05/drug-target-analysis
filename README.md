# Drug Target Interaction Analysis

## Objective
To analyze interactions between drug compounds and biological targets.

## Background
Drug–target interaction analysis is important in identifying potential therapeutic candidates.

## Dataset
Data collected from public databases such as PubChem or BindingDB.

## Methodology
- Data preprocessing using pandas
- Analysis of drug–target pairs
- Visualization using matplotlib

## Results
Different drug compounds show varying levels of interaction with biological targets.

## Visualization
A heatmap or bar chart was used to represent interaction frequency between drugs and targets.

## Key Insight
Some drug–target pairs show stronger interaction patterns, indicating potential importance for further study.

## Tools Used
Python, pandas, matplotlib

## Future Scope
Can be extended using machine learning models to predict binding affinity.
